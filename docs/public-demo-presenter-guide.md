# Atlas Public Demo Presenter Guide

1. Open `/mission-control/`.
2. Select a sample project: `Piketon Advanced Reactor COL Assembly`, `HALEU UF6 Highway Shipment Readiness`, or `ForgeWorks Safety-Related Valve Supplier Review`.
3. In `Overview`, explain the project purpose, stage, represented scope, unresolved findings, and primary next action.
4. Open `Requirements / application` or `Requirements` and inspect one requirement, its cited basis, linked evidence, missing support, and review status.
5. Use `Load sample evidence`, `Attach evidence`, or `Replace evidence` to resolve one demonstrated gap. Use only sample or non-sensitive material.
6. Open `Findings and actions` and show the changed finding and responsible role. Then open `History` to show the saved action record.
7. Open `Report`, then use `Download HTML report`, `Download evidence/action register`, or `Print / save PDF`.
8. Reload the page to demonstrate saved progress.

Boundary: this public demo uses browser-local storage only. Other devices will not see the demo workspace, and clearing browser data removes it. Evidence processing runs in the browser for supported TXT, Markdown, CSV, and JSON files. Reviews and transportation acceptance are demonstration-only and do not represent NRC, DOT, PHMSA, supplier, carrier, or human authorization. A licensed private workspace would add authenticated users, controlled storage, production evidence custody, permissions, and authorized review workflows.
